# Anup Singh - Portfolio

Personal portfolio website showcasing 8.5+ years of experience as a Senior Software Engineer & Team Lead.

**Live:** [anup-singh.netlify.app](https://anup-singh.netlify.app)

## Sections

- **Hero** - Animated intro with particle background, typed text rotator, and profile photo
- **About** - Professional summary, stats, and personal details
- **Skills** - Technical stack across 6 categories (Languages, Frontend, Backend & CMS, Database, Cloud & DevOps, Other)
- **Experience** - Career timeline at GALE, Exito Media Concepts, and Radical Networks
- **Projects** - Featured client work (CPPIB, Fogo de Chao, Enercare, Milk PEP)
- **Education** - MCA and BIT degrees
- **Achievements** - Key career accomplishments
- **Contact** - Email, phone, and social links

## Tech Stack

Single-file HTML portfolio with embedded CSS and JavaScript. No build tools required.

- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Outfit + DM Sans)
- CSS Grid & Flexbox for responsive layouts
- Intersection Observer API for scroll animations

## Features

- Fully responsive (mobile, tablet, laptop)
- Animated particle network background
- Typed text rotation effect
- Scroll-triggered reveal animations
- Animated stat counters
- 3D tilt effect on skill cards
- Custom cursor (desktop only)
- Touch-optimized for mobile devices

## Run Locally

```bash
# Clone the repo
git clone https://github.com/anup0022/anup-portfolio.git
cd anup-portfolio

# Serve with any static server
python3 -m http.server 8765
# Open http://localhost:8765
```
